# Component ledger

A row is complete when lane, source and pin, author and licence, and the
reference artifact are all filled. An incomplete row blocks that component's
visual sign-off.

Lanes: **verbatim** is a class-for-class port of a sourced component.
**translation** re-expresses a source's structure in this page's own classes;
nothing is copied from it. **own** has no source, so its only check is a
person opening the render.

Captures of other companies' pages live in `refs/external/`, which is not
committed (this repository is public and those pages are not ours to publish).
Each row records the link and the file's hash, so a capture can be fetched
again and compared.

## Open: the photograph on the computer

The computer and keyboard wear the owner's photograph of a Macintosh Classic II, and
`public/study/study.glb` carries its pixels, so publishing the site publishes them. The
photograph's own screen reads https://oldcrap.org, so it is very likely someone else's
picture. Its badge also puts Apple's logo and the "Macintosh Classic II" wordmark on the
model, where the modeled version had left the badge blank. Before the site is published,
either the photograph's owner allows it, or the projection gives way to the modeled skin
(or to a photograph the owner takes), with the badge blanked either way.

## Open: the capture take

The saved capture thread behind the film's last stills did not finish: the desktop still
shows a run of unreadable characters in the first answer, and the tube still ends on the
follow-up's step-limit error. A fresh take through the demo stack, then a re-render of

the follow-up's error, so the tube's still matches (ssim 0.954). The desktop and phone stills
froze the first answer instead, and they miss the picture (ssim 0.835 and 0.695) while every
other fact holds: size, theme, both answers, scroll, selection, an empty box, no focus taken.

## Open: the coss licence

The coss repository's README licenses it under AGPL-3.0-only, with exceptions for
